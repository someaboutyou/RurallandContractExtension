## 二、调查批次管理

选中批次后的详情区改为「统计 + 清单 + 批量导出」布局：

### 1. 批次统计
显示本批次：
- 发包方数量
- 承包方数量
- 家庭成员数量
- 承包地块数量
- 承包合同数量

实测批次 35：10 个发包方、527 个承包方、1812 个家庭成员、3097 个地块、527 份合同。

### 2. 本批次发包方清单
- 只读展示，不在本页编辑。
- 支持多选，并显示已选数量。
- 支持按发包方关键字查询。

### 3. 批量导出入口
- 复选框：发包方调查表、承包方调查表、地块调查表。
- 「导出」按钮按勾选的发包方批量导出。
- **当前为入口占位**：具体导出逻辑待发包方/承包方/地块管理的导出功能实现后复用。

### 4. 进入任务
- 批次详情提供「进入任务」按钮。
- 点击后把当前批次写入数据库 `users.current_survey_batch_id`。
- 下次进入系统时，相关页面默认显示该批次。
- 点击后跳转到「承包方管理」调查页面。

### 5. 移除内容
- 删除原「发包方调查」Tab 及相关弹窗/逻辑。

## 三、承包地块管理

新增页面 `/parcels`（`ParcelOverviewView.vue`）：

### 1. 树形展示
- 以**承包方为父行**、承包地块为子行。
- 父行显示：`承包方名称(地块数:N)(户号:XXXX)`，并汇总面积。
- 默认全部展开。

### 2. 列
地块名称、地块编码、二轮合同面积(亩)、实测面积(亩)、延包面积(亩)、确权面积(亩)、土地利用类型、地块类别、基本农田、是否确股地块、备注。

字段口径：
- 二轮合同面积：`yhtmjm`（原合同面积亩），缺省由 `htmj`（㎡）换算。
- 实测面积：`scmj`（㎡）换算为亩。
- 确权面积：`htmjm`（确权合同面积亩），缺省退回实测。
- 延包面积：Web 暂无 `ybmj` 字段，固定显示 0.00。
- 土地利用类型：字典 `nyt2539_c09_land_use`。
- 地块类别：字典 `nyt2539_c07_parcel_category`（10=承包地块）。
- 基本农田 / 是否确股地块：`sfjbnt` / `sfqqqg`（是/否）。

### 3. 查询
- 支持按**发包方或承包方**的名称/编码模糊查询。
- 发包方查询通过「承包地块关系 + 发包方结果表」反查承包方。

### 4. 添加 / 删除 / 编辑
- 支持调查批次选择（默认读取「进入任务」的当前批次）。
- 「添加」：选择承包方后新增地块；列表场景允许只填属性，图形后续在调查成果中补充。
- 「删除」：多选地块，填写删除原因后逐块删除。
- **双击地块**：打开该承包方的调查详情，并直接切到「地块信息」面板。

### 5. 导出
导出按钮提供两个选项：
- **地块调查表**：Word（单地块 `.docx`，多地块 `.zip`）。
- **地块示意图**：PDF（**按户输出**，一户一个 PDF；多户打包 `.zip`）。

地块示意图复用现有 `poltsketchmap` 打印母版，按户展示该户全部承包地块；服务端通过无头 Edge/Chrome 打印为 PDF。

## 六、后端接口与数据模型

### 1. 当前批次
- `users` 新增 `current_survey_batch_id`（含启动迁移）。
- `GET /api/v1/surveys/current-batch`
- `PUT /api/v1/surveys/current-batch`
- `GET /api/v1/surveys/batches/{batch_id}/stats`

### 2. 承包地块
- `GET /api/v1/surveys/parcels/overview`
  - 按承包方分组返回地块清单。
  - 支持发包方/承包方模糊查询、分页。
  - 返回 `contractorUid` 供编辑操作使用。
- `POST /api/v1/surveys/parcels/export-docx`
  - 导出承包地块调查表 Word。
- `POST /api/v1/surveys/parcels/export-sketch-pdf`
  - 按户导出地块示意图 PDF。

### 3. 渲染与模板
- `contract_template_service.build_parcel_survey_html`：只渲染选中地块的《承包地块调查表》。
- `cadastral_survey.html` 新增 `parcel_only`、`include_point_sheets` 开关，不影响原完整地籍调查表导出。
- 新增 `parcel_survey_docx_service.py`：HTML 母版转 docx。
