## 第一版原则

- 先把模块边界搭清楚
- 先提供假的内存数据，方便页面和接口联调
- 业务状态先保留枚举字段
- 工作流与 GIS 先抽象接口，不强耦合到具体实现

## 后端模块分层

```text
app/
  api/         路由层
  core/        配置、常量、通用响应
  domain/      领域模型
  repositories/ 数据访问层
  schemas/     请求响应模型
  services/    业务逻辑层
```

## 前端模块分层

```text
src/
  api/         接口请求
  components/  公共组件
  layout/      页面框架
  router/      路由
  stores/      状态管理
  views/       页面
```
